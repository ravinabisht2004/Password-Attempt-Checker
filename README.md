**Password Attempt Checker – Java Project**

1. This project is a simple password verification system developed using Java.
2. It allows users a maximum of three attempts to enter the correct password.
3. A `while` loop is used to control the number of attempts.
4. An `if-else` statement checks whether the entered password is correct or incorrect.
5. If the user enters the wrong password three times, access is denied and the account is locked.
